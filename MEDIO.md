# Medio — Selldone Layout

**Medio Electronics** (package `medio-electronics`) is a Layout of the Selldone shop **Digini** (shop 15549, xapi name `digini-hzgablru`), an electronics store with one seller. It was made on 10–11 November 2026 for the owner's request "like currys.co.uk": the reference's page sections and its big-retailer feel, in Medio's own brand (never the reference's name, logo, slogans or images). It runs only on **medio.selldone.shop** (domain 1243, whose Home is the shop page). The shop's other addresses carry other Layouts (Digito, Besti, Argon, Senso). It started from Argon 1.0.9 (`argon-layout`, `git clone`, history kept; `ar-` → `md-`), so every shared feature is kept: the shared theme switcher (a footer row, showcase only), the shared region switcher (language and currency in the header), real deal timers, rings inside the box, the one-row gallery, named colour tiles, the compare page, the desk account, the basket drawer (design C), the guest order code fix, the listing motion and the deals list that stops asking for more.

The mockups are `../digini-design/medio-home.html`, `medio-category.html` and `medio-product.html` (screenshots in `../digini-design/shots/medio-*.png`). The photo prompts for Codex are `../digini-design/codex-photos-medio.md`.

## Data rules

- **One catalogue read** (`medio.ts` `catalogue()`), shared by the home, header, hub, cards and add-ons; shared reads (catalogue, tags, categories) are tried up to four times on a 429 (SYNC §16).
- **Tags are found, not named** (`tagged()`); a tag with no products shows nothing; a new tag adds its own "Popular picks" tab and hub choice.
- **Deal clocks count to the deal's own end** (`dealEnd`, one shared ticker); without an end date there is no clock.
- **Delivery lines come from the shop's own delivery ways** (`deliveryKinds`): "Available for delivery", "Collection available" only when such a way is on.
- **No product counts in shopper words** (a result count on a results page only).
- **Theme is a showcase feature**; a merchant's theme is the settings file.
- **Rings inside the box**; focus rings too. **No vendor UI.**
